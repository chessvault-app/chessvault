# Contributing

Chess Vault is developed by one person, in the open, and is not taking
pull requests. The source is here so that you can read it, build it,
run it and fork it under the GPL, not because the project is looking
for hands. A pull request will be closed without review; please do not
spend time on one.

**Bug reports and feature requests are welcome.** Open an
[issue](https://github.com/chessvault-app/chessvault/issues). For a bug,
give the version (Settings shows it), the platform, and what you did.
For a feature, say what you were trying to do and where the app stopped
you; that is more useful than a proposed design, and whether it gets
built is decided against `PRODUCT.md`. Security problems go through
`SECURITY.md` instead.

**Building it yourself.** `README.md` has the setup. `npm run verify`
is what CI runs on every push. `CLAUDE.md` is the repository's standing
rules, and `DESIGN.md` and `docs/` say why things are the way they are,
which is the most useful thing to read before forking.
